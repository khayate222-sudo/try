# pawplay

スマホのブラウザで遊ぶ、猫のための小さな狩りゲーム。ねずみ・てんとうむし・羽・小さなアリ・小バエ・蜘蛛、速度3段階、草原／夜の庭、効果音の切り替えに対応。獲物は移動・静止・隠れる動作をランダムに切り替えます。設定は端末内に保存されます。外部APIや追加パッケージは不要です。

## ステージ

- **平面の狩り場**：従来の猫動画のような見下ろし画面。獲物が走る・止まる・隠れる動作を切り替えます。移動を高速化し、速度は「ゆったり・すばやく・猛ダッシュ」の3段階です。
- **奥行きダッシュ**：前に走り続ける一人称の遠近感をCanvasで描画。道や木々が手前へ流れ、奥から来る獲物が左右・上下に揺れながら近づきます。通過前にタップすると、距離に応じて30／20／10ポイント。通過した獲物は得点になりません。獲物の種類、速度、草原／夜の庭を両ステージで選べます。

- **壁のぼり**：蜘蛛や小さな虫が正面の壁をのぼります。短いダッシュ、探索、停止、急旋回をランダムに切り替え、近くへのタップから逃げます。てんとうむし・アリ・小バエ・蜘蛛を選べ、ねずみと羽はこのステージでは無効です。小さなアリ・小バエは捕獲で20点、他は10点です。

虫の動きは平面・奥行き・壁で共通の不規則な運動モデルを使います。脚は移動距離に連動して動き、止まっている間は歩き続けません。虫の色を「くっきり」にすると、明るい背景では黒っぽく、暗い背景では淡い色に変わります。「自然な色」では茶色系になります。大きさは「極小・ふつう・大きめ」。小さい虫でもタッチ判定を最低18pxに保ちます。

ステージは設定画面のカードで切り替えます。プレイごとに得点をリセットし、休憩画面に今回のポイント・捕獲数・時間を表示します。描画や判定に外部3Dライブラリは使いません。

## 開発

Node.js 22以上で実行します。

```sh
npm start
npm test
npm run build
```

標準ポートは3000（`PORT`で変更可能）。`npm run build` は公開用ファイルのみを `dist/` にコピーします。`dist/` をHTTPS対応の静的ホスティングに配置するとスマホから使えます。ソースの場所にかかわらず実行でき、サブディレクトリ配下にも対応しています。

## GitHub Pagesで公開

`.github/workflows/pages.yml` にテスト → ビルド → 公開の設定があります。

1. このコードを `main` にpushします。
2. [リポジトリのPages設定](https://github.com/khayate222-sudo/try/settings/pages) で、Build and deployment の Source に **GitHub Actions** を指定します。利用プラン・組織のポリシーによりPagesを有効化できない場合は、別の静的ホスティングが必要です。
3. Actionsタブから **Publish pawplay** を実行します。有効化前に失敗した実行は再実行してください。以降は `main` の更新で公開されます。
4. 実行結果に表示される `github-pages` のURLをスマホで開きます。独自ドメイン設定がない場合の予定URLは `https://khayate222-sudo.github.io/try/` です。デプロイ成功とHTTP応答を確認するまでは公開済みとは見なせません。

## スマホでの操作

- プレビューもタッチできます。相手と背景を選び、画面下のボタンで開始します。
- 獲物にタッチすると捕獲。休憩ボタンは約1秒長押し（キーボードではEnterまたはEscape）。3分ごとに休憩画面が表示され、別タブに移ると一時停止します。
- iPhoneは共有メニュー、Androidはブラウザのメニューから「ホーム画面に追加」が可能です。初回のオンライン読み込みとサービスワーカーの準備完了後は、オフラインでも遊べます。ブラウザ設定でストレージが制限されるとオフライン機能は利用できません。
- スリープ抑止は対応ブラウザのHTTPS接続で利用します。通常のブラウザ表示ではOSとブラウザの操作領域が残ります。

猫の反応には個体差があります。スマホを平らな場所に置き、見守りながら短時間ずつ遊んでください。音は初期状態でオフです。画面遊びの後には、本物のおもちゃで捕まえる遊びもどうぞ。
